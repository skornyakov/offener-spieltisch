# Spielbrücke: Webseite

Webseite der Spielbrücke (spielbruecke.de) mit der Karte der Spieltreffpunkte und der Spielwoche vom 25. bis 31. Januar 2027. Gebaut mit [Hugo](https://gohugo.io), gepflegt mit [Pages CMS](https://pagescms.org), veröffentlicht über GitHub Pages.

- Inhalte bearbeiten: auf [app.pagescms.org](https://app.pagescms.org) anmelden und dieses Repository öffnen.
- Einrichtung, Karte und Pflege: siehe [ANLEITUNG.md](ANLEITUNG.md).

Lokal ansehen (nur für Technikinteressierte): Hugo 0.167.0 installieren, dann `hugo server` und http://localhost:1313 öffnen.

Schriften: Bricolage Grotesque und Inter, beide unter der SIL Open Font License (siehe `static/fonts/`).
